# Parallel Dual-Controller Security Framework

A MATLAB/Simulink implementation of a **Parallel Dual-Controller Defense Framework** designed to detect stealthy cyber-attacks and sensor spoofing in Cyber-Physical Systems (CPS). By evaluating discrepancies between two parallel control signals ($u_a$ vs. $u_b$) under a time-varying parameter $a(t)$, this framework exposes hidden attacks and invalidates false data injection.

---

## 🔑 Core Features

- **Control Signal Cross-Checking**: Monitors discrepancies directly at the control effort level by comparing the main controller signal ($u_a$) against an isolated shadow controller signal ($u_b$).
- **Time-Varying Parameter Dynamics ($a(t)$)**: Integrates a dynamic parameter $a(t)$ within the physical plant. Because the adversary lacks real-time knowledge of $a(t)$, their assumed attack law introduces an uncompensated zero mismatch.
- **Isolated Shadow Loop Execution**: The shadow controller ($u_b$) runs inside a secure, local processor environment with zero network exposure, creating an untamperable reference baseline.
- **Noise-Tolerant Detection Thresholds**: Optimized anomaly thresholds ensure clear detection spikes ($\Delta u$) during active attacks while preventing false alarms caused by measurement noise.

## 📐 Architecture & Detection Framework

Standard single-loop control systems are vulnerable to **sensor spoofing**. An adversary can manipulate physical plant states while sending fake, "flat" sensor readings over the network to cover up physical damage.

This dual-controller architecture forces the adversary into an **unmaskable dilemma**:

$$\text{Residual } (\Delta u) = \vert{}u_a - u_b\vert{} > \text{Threshold}$$

Where:
- **$u_a$**: Primary control signal generated by Controller A (connected to the network).
- **$u_b$**: Reference control signal generated by Controller B (isolated shadow controller).

### Why Stealthy Attacks Fail

1. **If the attacker DOES NOT spoof sensors**: The unknown parameter $a(t)$ creates a structural zero mismatch. The plant output explodes, forcing $u_a$ to diverge rapidly from $u_b$ to stabilize the system.
2. **If the attacker DOES spoof sensors**: The fake, flat feedback sent across the network forces Controller A ($u_a$) to compute an artificial control effort that instantly conflicts with the isolated shadow signal ($u_b$).

> **Result**: Stealthy cyber-attacks become mathematically impossible because the adversary cannot fake control signal consistency.
